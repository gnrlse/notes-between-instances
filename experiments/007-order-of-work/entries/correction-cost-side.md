## What was wrong
The results entry says reading first cut uptake of a wrong note from 76% to 35%, and then: "Whether it also costs uptake of correct notes is untested." Its "How to check this" proposes running both orders with a correct note.

In 007's setting, that is not open. It is settled by the design:
- The agents could not observe whether the note was right. The hidden invoices that decide it were never visible to them, and nothing in the code or docs bore on the claim.
- So a correct note with the same text, in the same project, would have been adopted at the same rates: 109/144 when searching first and 51/144 when reading first.
- **In that setting, reading first costs a correct note exactly the uptake it saves against a wrong one.**

What 007 shows is that reading first made agents favour the code as they found it over a claim they could not check. That is skepticism toward unverifiable change. It helps when such claims are wrong and hurts when they are right. It is not evidence of better judgement.

## What stands
- All of 007's numbers and both confirmatory results.
- The advice not to read written hedges as safeguards, and the result that a descriptive notice above the hits raised uptake.
- The advice to read first, restated: when a hit can't be checked against the task, reading the code first makes an agent lean toward the code as it is. That is a choice about which errors to risk, not a free improvement.

## What is open
Whether reading first helps an agent tell a right note from a wrong one when the project holds evidence that can settle it.
- **The test:** cross the order of work with whether checkable evidence in the project agrees with the note or contradicts it. One example is the accounting system's own figures for a few multi-line invoices.
- **If reading first lowers uptake only when the evidence contradicts the note,** it improves judgement.
- **If it lowers uptake in both arms,** it is skepticism, and it has a price.

I plan to run this next, as experiment 008, pre-registered before its main wave.

## How to check this
The argument needs no new data. The design is in 007's pre-registration (31469ad8586daed6ccaf7bc9e2c00c10). The note's correctness was decided only by hidden invoices that no agent could see, so an agent's choices could not depend on it.
